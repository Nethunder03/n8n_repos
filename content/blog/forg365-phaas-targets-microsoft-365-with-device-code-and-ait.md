# Forg365 : Une nouvelle plateforme de PhaaS sophistiquée cible Microsoft 365 ![Forg365 : Une nouvelle plateforme de PhaaS cible Microsoft 365 par vol de session AitM et Device Code](https: Le paysage de la cybercriminalité continue de s'industrialiser avec l'émergence d'une nouvelle plateforme de **Phishing-as-a-Service (PhaaS)** baptisée **Forg365**. Ce service clé en main, commercialisé activement sur Telegram, cible spécifiquement les environnements d'entreprise **Microsoft 365** à l'aide de tactiques hybrides redoutables pour contourner l'authentification multifacteur (MFA). Disponible pour la somme de 400 dollars par mois (ou 3 800 dollars par an), Forg365 démontre le niveau de maturité technique atteint par les concepteurs de kits de phishing modernes. --- ## Détails techniques de l'attaque Forg365 L'attaque orchestrée par la plateforme Forg365 se distingue par sa capacité à contourner les mesures de sécurité standard grâce à un enchaînement d'étapes sophistiquées : ## 1. La génération de leurres par Intelligence Artificielle (IA) Les opérateurs de Forg365 exploitent l'assistance de l'IA pour concevoir des e-mails d'hameçonnage hautement convaincants et exempts de fautes d'orthographe ou d'incohérences de style, rendant la détection humaine particulièrement difficile. ## 2. L'exploitation d'infrastructures d'envoi légitimes Pour franchir les barrières des passerelles de sécurité de messagerie (Secure Email Gateways), la plateforme utilise des services de distribution d'e-mails réputés, tels que **Amazon Simple Email Service (Amazon SES)** et **Twilio SendGrid**. Les e-mails de phishing proviennent donc de serveurs légitimes avec des configurations SPF, DKIM et DMARC valides. ## 3. Les tactiques d'Adversary-in-the-Middle (AitM) et de Device Code Phishing Une fois que la victime clique sur le lien, elle est confrontée à un mécanisme de redirection élaboré conçu pour masquer la destination finale. Forg365 utilise deux méthodes redoutables : * **Device Code Phishing** : L'attaquant incite la victime à saisir un code d'authentification d'appareil sur une page Microsoft légitime. Une fois saisi, l'attaquant obtient un jeton d'accès complet au compte sans avoir besoin de connaître le mot de passe. * **Adversary-in-the-Middle (AitM)** : Un serveur mandataire (proxy) s'interpose entre la victime et le véritable service Microsoft 365. Lorsque l'utilisateur s'authentifie, le kit intercepte les identifiants ainsi que les jetons de session (cookies) générés après la validation du MFA, permettant à l'attaquant de maintenir un accès persistant. --- ## Impact sur les organisations L'impact d'une telle compromission est critique pour les entreprises. Une fois la session Microsoft 365 volée, la plateforme Forg365 facilite les opérations post-compromission de manière automatisée. Les attaquants peuvent ainsi : * Accéder à l'ensemble de la messagerie de l'organisation. * Créer des règles de transfert de courrier invisibles pour l'utilisateur afin d'exfiltrer des données sensibles en continu (Business Email Compromise). * Se propager en interne en envoyant des messages malveillants à partir de comptes de confiance pour compromettre d'autres collaborateurs. --- ## Recommandations de sécurité Pour contrer l'efficacité de Forg365, les équipes de sécurité informatique doivent adapter leurs défenses : 1. **Désactiver ou restreindre les flux de code d'appareil (Device Code Flow)** : Bloquez l'utilisation de cette méthode d'authentification via des politiques d'Accès Conditionnel (Conditional Access) dans Microsoft Entra ID pour tous les utilisateurs n'en ayant pas un besoin strict. 2. **Adopter le MFA résistant au Phishing** : Migrez vers des solutions d'authentification forte insensibles aux attaques AitM, telles que les clés de sécurité matérielles FIDO2, Windows Hello for Business ou l'authentification basée sur des certificats. 3. **Surveiller les configurations Exchange Online** : Implémentez des alertes automatiques en cas de création de règles de redirection de boîte aux lettres suspectes ou de connexions suspectes provenant d'adresses IP ou d'appareils non répertoriés. 4. **Former vos collaborateurs** : Intégrez des modules spécifiques sur les menaces émergentes comme le phishing par code d'appareil, en insistant sur le fait qu'aucun service informatique ne demande de valider un code généré à la volée sans action délibérée de leur part. --- ## Sources * Source: The Hacker News - https:
