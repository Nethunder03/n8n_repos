# Faille critique dans Zimbra Classic Web Client : Vos e-mails sous la menace d'une exécution de code ![Une faille critique dans Zimbra permet d'exécuter du code malveillant via de simples e-mails](https: L'éditeur de la suite collaborative Zimbra vient de lancer un avertissement urgent à ses utilisateurs. Une vulnérabilité de sécurité critique, touchant le **Classic Web Client**, pourrait permettre à des attaquants d'exécuter du code malveillant au sein des sessions des utilisateurs légitimes. Cette faille, qui n'a pas encore reçu d'identifiant CVE officiel, est activement ciblée par des mesures correctives d'urgence. --- ## Détails techniques de la menace La vulnérabilité en question est un **Stored Cross-Site Scripting (Stored XSS)** ou XSS persistant. Elle réside dans le traitement des e-mails entrants par le client web classique de Zimbra. Lorsqu'un e-mail contenant un code malveillant spécialement conçu est envoyé à une victime, le serveur Zimbra stocke ce message dans la base de données de la messagerie. Dès que la victime ouvre cet e-mail dans son navigateur via l'interface du Classic Web Client, le script malveillant (généralement du JavaScript) s'exécute automatiquement. La dangerosité de cette attaque réside dans le fait qu'elle s'exécute directement dans le contexte de la session active de l'utilisateur. Aucune interaction complexe autre que l'ouverture de l'e-mail n'est requise de la part de la victime pour déclencher la charge utile. --- ## Quel est l'impact pour les entreprises ? Si elle est exploitée avec succès, cette vulnérabilité offre aux cybercriminels un accès quasi illimité aux données de la victime. Les impacts potentiels incluent : * **Vol de données de session :** Les attaquants peuvent dérober les cookies de session et s'authentifier à la place de l'utilisateur sans connaître son mot de passe (Session Hijacking). * **Accès intégral à la messagerie :** Lecture, envoi et suppression d'e-mails, compromettant la confidentialité des échanges de l'organisation. * **Modification des paramètres :** Altération des règles de transfert d'e-mails pour intercepter silencieusement les communications futures ou modification des informations de récupération de compte. Historiquement, les serveurs Zimbra ont toujours été des cibles privilégiées pour les acteurs étatiques et les cybercriminels. Des failles similaires, telles que **CVE-2025-27915**, **CVE-2023-37580** ou **CVE-2024-27443**, ont déjà été massivement exploitées dans le passé à des fins d'espionnage ou de vol d'identifiants. --- ## Recommandations et mesures d'atténuation Pour protéger vos infrastructures contre cette menace critique, plusieurs actions immédiates sont recommandées : 1. **Appliquer la mise à jour d'urgence :** Zimbra exhorte l'ensemble de ses clients à déployer immédiatement la version **Zimbra Collaboration Suite (ZCS) 10.1.19**. 2. **Privilégier le Modern Web Client :** Si la mise à jour ne peut pas être planifiée instantanément, incitez vos collaborateurs à utiliser l'interface moderne (Modern Web Client) qui n'est pas affectée par cette vulnérabilité spécifique. 3. **Sensibilisation et surveillance :** Sensibilisez vos équipes IT à surveiller les connexions anormales sur les comptes de messagerie et examinez les logs d'accès à la recherche de requêtes Web atypiques. Ne tardez pas à appliquer ces correctifs, car les vulnérabilités de type XSS sur Zimbra sont généralement militarisées très rapidement par les attaquants. ## Sources Source: The Hacker News - https:
